# Habit Tracker

A web-based habit tracking application designed to help users build and maintain consistent daily habits through a simple, interactive, and engaging interface.

## Features

- Track daily habits and tasks
- Mark completed tasks with an interactive checklist
- Progress tracking for daily goals
- Celebration animation when all tasks are completed
- Random motivational messages upon completion
- Custom YIPPEE sound effect
- Responsive and user-friendly interface
- Lightweight frontend implementation

## Technologies Used

- HTML5
- CSS3
- JavaScript
- MP3 Audio
- GIF Animation
